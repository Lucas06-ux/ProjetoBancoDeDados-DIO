# ProjetoBancoDeDados-DIO

Esse repositório tem o projeto de Banco de Dados iniciado através da plataforma DIO. O desafio foi refinar o modelo acrescentando:

Cliente PJ e PF – Uma conta pode ser PJ ou PF, mas não pode ter as duas informações;

Pagamento – Pode ter cadastrado mais de uma forma de pagamento;

Entrega – Possui status e código de rastreio;

As outras tabelas do modelo já existiam no projeto.

# O que é esse Modelo:

É um cenário de E-commerce simples que tem o objetivo de avaliar o nosso conhecimento adquirido durante as aulas do curso da DIO.me para avaliar nossa capacidade na criação de tabelas, atributos e cardinalidades de cada uma, tendo que fazer sentido com o que foi requisitado e em um cenário de E-commerce.
